# ZCode App Launcher v1.1.0

在 ZCode 桌面客户端左侧栏「插件市场」下方、任务列表上方放一个竖排启动方块：点一下打开软件，
或者按顺序拉起一整条软件链。

## 本次新增

### 分组菜单（一级 / 二级）

一个按钮里配置多个程序时，它自动成为一组：

- 点**一级行**：按顺序整组启动
- 点右侧 **▸** 展开：出现每个程序的二级菜单，点哪个就只启动哪个
- 每个步骤可以单独起名，作为二级菜单的显示名；不填则自动用程序名

### 排序

不用再删除重建：

- 「启动项」列表里用 **↑ / ↓** 调整一级按钮顺序
- 每个步骤卡片标题旁用 **↑ / ↓** 调整二级步骤顺序

### 个性化页

配置面板拆成 **启动项 / 个性化** 两个标签页：

- **字号**：侧栏方块、设置页分别设置（11–18）
- **背景不透明度**：侧栏、设置页各一条 0–100% 滑杆
  - 100% 不透明，0% 完全透明
  - 调低后可以透出 ZCode 的背景/壁纸
- 改动实时预览，保存后生效

### 亮暗跟随系统

自动适配系统/客户端主题，浅色与深色都不需要手动切换。

### 安装弹窗（三选项）

ZCode 正在运行时安装会弹出选择框：

| 选项 | 行为 |
| --- | --- |
| **是，立即重启并使用** | 请求退出，托盘未退则强制结束 → 注入 → 自动重开 |
| **否，关闭后自动重启并使用** | 等你手动关闭 → 注入 → 自动重开 |
| **否，关闭后自动使用，不重启** | 等你手动关闭 → 注入，不重开 |
| **取消** | 不做任何修改 |

三种方式都由独立守候进程完成，不随 ZCode 退出被结束。

## 修复

- 修复字号设置没有真正保存（注入端只保留了旧字段）
- 修复暗色模式下字号下拉是白底白字
- 放大二级菜单的展开按钮，点击区域更明显
- 安装弹窗被 `windowsHide` 隐藏的问题
- 「立即重启」只关闭窗口、托盘进程仍在的问题

## 安装

1. 完全退出 ZCode（托盘右键 → 退出）
2. 解压后执行：

   ```bash
   node install.mjs
   ```

   或直接双击 `install.cmd`。

3. 重新打开 ZCode，左侧栏即可看到启动方块。

安装时如果 ZCode 在运行，按弹窗选择重启方式即可；建议关闭后等待约 15 秒，
避免 `app.asar` 仍被占用。

## 使用

- 点方块底部 `⚙` →「＋ 新增按钮」→ 填写名称、图标
- 每一步选「选择程序」或「写命令」；多个步骤就是一条启动链
- 一级点击整组启动，点 `▸` 展开后单独启动
- 顺序在配置里用 ↑/↓ 调整
- 字号和背景不透明度在「个性化」页调整

## 环境要求

- Windows 10 / 11
- Node.js 18+
- ZCode 桌面客户端（在 3.18.x 验证）

## 校验

- 包内 `SHA256SUMS.txt`：压缩包内每个文件的 SHA-256
- Release 附件 `zcode-app-launcher-1.1.0.zip.sha256`：压缩包本身的 SHA-256

压缩包的哈希无法放进压缩包内部——写入这个文件会改变压缩包自身的哈希。

```bat
certutil -hashfile zcode-app-launcher-1.1.0.zip SHA256
```

## 已知限制

- 非官方修改客户端，ZCode 升级后需要重新执行一次 `node install.mjs`
- 目前仅支持 Windows

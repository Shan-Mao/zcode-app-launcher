# ZCode App Launcher v1.1.0

在 ZCode 左侧栏「插件市场」下方、任务列表上方放一个竖排启动方块：点一下打开软件，
或者按顺序拉起一整条软件链。

## 本版新增：分组菜单

一个按钮里配置多个程序时，它自动变成**分组**：

- 点**一级行**：按顺序整组启动（原来的链式启动）
- 点右侧 **▸** 展开：出现每个程序的子项，点哪个就只启动哪个
- 每个步骤可以起名（编辑器里的「名称」），不填就用程序名

## 个性化

- **亮暗跟随系统**：不用手动切换，系统/客户端切到浅色时方块与设置面板自动适配
- **独立个性化页**：字号与背景不透明度集中在「个性化」标签页
- **字号分开设置**：侧栏方块和设置页各有一个字号选择（小 11 / 标准 12 / 大 14 / 特大 16 / 极大 18）
- **背景不透明度分开设置**：侧栏与设置页各一条滑杆（0–100%），调低可透出 ZCode 背景/壁纸

## 修复

- 修复字号设置没有真正保存（注入端只保留了旧字段）
- 修复暗色模式下字号下拉是白底白字
- 放大二级菜单的展开按钮，点击区域更明显

## 其他亮点

- **竖排启动方块**：图标在左、名称在右，位于「插件市场」与任务列表之间
- **两种配置方式**：每步可「选择程序」（文件选择框）或「写命令」（cmd 命令行）
- **链式启动**：多步按顺序执行，每步可设置等待毫秒数
- **排序**：配置面板用 ↑/↓ 调整一级按钮和二级步骤，不再需要删除重建
- **零常驻进程**：没有 HTTP 服务、没有开机自启；点按钮时由 ZCode 主进程执行一次命令链
- **本地配置**：保存在 `%APPDATA%\zcode-app-launcher\config.json`
- **安全可逆**：注入前生成字节级备份，`node uninstall.mjs` 一键还原

## 安装

1. 完全退出 ZCode（托盘右键 → 退出）
2. 解压后执行：

   ```bash
   node install.mjs
   ```

3. 重新打开 ZCode，左侧栏即可看到启动方块

安装时如果 ZCode 还在运行，会弹出三选项对话框：

- **是，立即重启并使用**：请求退出（托盘未退则强制结束）→ 注入 → 自动重开
- **否，关闭后自动重启并使用**：等你关闭 → 注入 → 自动重开
- **否，关闭后自动使用，不重启**：等你关闭 → 注入，不重开

建议关闭客户端后等待约 15 秒，避免 `app.asar` 仍被占用。

## 使用

点方块底部「⚙ 配置」→「＋ 新增按钮」→ 填写名称和图标 → 每一步选择程序或写命令 →
保存。加多个步骤就是一条启动链，一级点击整组启动，展开后可以单独启动。

## 环境要求

- Windows 10 / 11
- Node.js 18+
- ZCode 桌面客户端（在 3.18.x 验证）

## 校验

- 包内 `SHA256SUMS.txt`：压缩包内每个文件的 SHA-256
- Release 附件 `zcode-app-launcher-1.1.0.zip.sha256`：压缩包本身的 SHA-256

压缩包的哈希无法放进压缩包内部——写入这个文件会改变压缩包自身的哈希。

```bat
certutil -hashfile zcode-app-launcher-1.1.0.zip SHA256
```

## 已知限制

- 非官方修改客户端，ZCode 升级后需要重新执行一次 `node install.mjs`
- 目前仅支持 Windows
- 方块依赖侧栏的 `sidebar-task-list-region` 锚点，官方大改侧栏结构时需更新
